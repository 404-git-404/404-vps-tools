# 使用命令

## VPS 初始化

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/404-git-404/404notfound/main/404notfound.sh)
```

## 更新 SmartDNS

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/404-git-404/404notfound/main/scripts/update-smartdns.sh)
```

## 安装 Domain Check

```bash
curl -fL https://raw.githubusercontent.com/404-git-404/404notfound/main/domain-check.sh -o /usr/local/bin/domain-check
chmod 700 /usr/local/bin/domain-check
```
